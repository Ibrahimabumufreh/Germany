☁️ المزامنة السحابية الفورية (Supabase)

اربط التطبيق بمشروعك المجاني على Supabase لتتم مزامنة كلماتك، تعديلاتك، وتصريفاتك لحظياً بين هاتفك والكمبيوتر وأي جهاز آخر، مع استمرار العمل بدون إنترنت.

🛠️ تعليمات تجهيز جدول Supabase (كود SQL للنسخ)

افتح SQL Editor في لوحة تحكم Supabase، الصق الكود التالي ثم اضغط Run (مرة واحدة فقط):

create table if not exists public.vocab_sync ( id text primary key, vocabulary jsonb not null default '[]'::jsonb, mastered jsonb not null default '[]'::jsonb, updated_at bigint not null default 0, updated_by text ); alter table public.vocab_sync enable row level security; create policy "Allow sync access" on public.vocab_sync for all using (true) with check (true); alter publication supabase_realtime add table public.vocab_sync;

💾 النسخ الاحتياطي ومشاركة التطبيق مع الأصدقاء

كل شخص يفتح التطبيق تُحفظ بياناته وتعديلاته داخل هاتفه هو فقط ولا تؤثر على تطبيقك أبداً. إذا أردت أن يبدأ أصدقاؤك بكلماتك وتصريفاتك الحالية، اضغط «ملف البداية للأصدقاء» وضع الملف بجانب index.html قبل رفعه.

✍️ إضافة كلمة يدوياً (عربي أو إنجليزي)

أدخل الكلمة الألمانية، وأضف الترجمة العربية أو الإنجليزية أو كلتيهما.

📷 استخراج المفردات من صورة (OCR)

ارفع صورة من الهاتف أو الكمبيوتر. يقوم التطبيق بتحسين وضوح الصورة تلقائياً قبل استخراج النص العربي والألماني وإزالة مستويات اللغة (A1 - C2) والأرقام.

📋 إضافة مجموعة كبيرة (النسخ واللصق)

الصق كلماتك بأي صيغة. يقوم التطبيق تلقائياً بـ: إزالة رموز المستوى (A1, A2, B1, B2, C1, C2) + حذف جميع الأرقام + وضع الترجمة العربية في خانتها + تحديد الأداة والتصنيف.
